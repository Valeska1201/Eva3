# Eva3

Página creada con React JS

Ajusta el proyecto React JS para lograr una aplicación con las siguientes funcionalidades: Como título "Mi libro de recetas", debe buscar recetas por nombre, por país o por ingrediente. Debe usar la API TheMealDB www.themealdb.com . Debe tener un CRUD donde pueda tener una lista de favoritos, crear su propia receta, leer las recetas de la API,  borrar recetas de listado de favoritos y poder agregar notas a cada receta. Que tenga un planificador semanal de recetas, donde se puedan agregar recetas desde la API o recetas creadas por usuario. Utilizar para guardar recetas e historial Local Storage. Utilizar useState, useEffect, fetch/axios y colores magenta y amarillo. Incorporar imágenes de recetas variadas atrás del título en forma de carrusel.
